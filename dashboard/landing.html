Understanding data

The data exists.
The combination does not.

For decades, organisations collected data in separate systems. When AI arrived, it met those same walls. The opportunity is not AI — it is giving AI something it can actually read.

How data has evolved · from fragmentation to intelligence
Types of data
Structured
Rows & Columns

Data that lives in defined fields. Databases, spreadsheets, records systems. Every entry has a schema. Every record has a place. The most common form of business data. The easiest to query in isolation.

Unstructured
Freeform Signal

Emails, documents, call transcripts, sensor readings, images. No fixed schema. The majority of data generated by any organisation is unstructured. Almost none of it is read systematically.

e.g. Sales call recording · Support email · Delivery photo · Field note
Semi-Structured
Partial Schema

Data with some structure but no rigid schema. JSON exports, XML feeds, event logs, API responses. It knows what it is, but different records carry different fields. Cross-system comparison is difficult.

e.g. API event log · System export · Webhook payload · Telemetry feed
Fragmented
Never Read Together

Data that exists correctly across all three forms above — structured, unstructured, semi-structured — held in systems that have never spoken to each other. The fourth problem. Not a data quality problem. A reading problem.

e.g. CRM + ERP + Finance + Risk · All accurate · All isolated

What is a legacy system

A company that has been operating for any length of time is running on multiple systems. One for each function. Each chosen at a different point in time, by a different team, to solve a different problem. As the business grew, it did not replace its systems. It added to them.

What a company looks like after 20 years of operation is a collection of accurate, well-maintained systems that have never spoken to each other. Each one correct. None of them aware of what the others know.

What this means in practice

The same entity exists in three of those systems simultaneously. In one, it is your highest-value account. In another, it has unresolved issues. In a third, it shows a consistent pattern of declining engagement.

Every team reads from their own system. Every decision is made from a partial view. The information needed to see the full picture exists. It is in the combination of all three. It has never been read that way.
